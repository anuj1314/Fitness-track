# Fitness Track

A personal fitness and vegetarian nutrition website, built from Markdown guides.

- **[content/](content/):** add or update `.md` guides here. Every build discovers
  them automatically and updates the website's guide library.
- **[website/](website/):** website code, build scripts, tests, and dependencies.
- **[Website instructions](website/README.md):** local setup and GitHub Pages deployment.

Push changes to `main` to trigger the GitHub Pages workflow. New guides need no
manual changes to the website's navigation.
